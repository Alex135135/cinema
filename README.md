# CineMatch

Готовое русскоязычное веб-приложение для подбора фильмов на Next.js 15, React 19, TypeScript и Redux Toolkit.

## Возможности

- Встроенный каталог из 18 фильмов (не требует API или базы данных)
- Поиск по названию, фильтрация по жанрам, годам, рейтингу
- Сортировка и страницы фильмов
- Рекомендации по настроению
- Избранное и список «Хочу посмотреть» с сохранением в localStorage
- Адаптивный дизайн

**Примечание:** вместо настоящих постеров используются авторские цветные карточки с эмодзи. Каталог статический; актуальные новинки автоматически не добавляются. Трейлеры и аккаунты не включены, так как автономная версия не использует внешние сервисы.

## Локальный запуск

Нужен Node.js 20 или новее.

```bash
npm install
npm run dev
```

Откройте http://localhost:3000.

## Размещение на Vercel

1. Распакуйте ZIP-архив.
2. Создайте новый репозиторий на GitHub и загрузите в него **содержимое** папки `cinematch` (не `node_modules`).
3. В Vercel выберите **Add New → Project → Import Git Repository**.
4. Framework Preset: **Next.js**; Root Directory: корень репозитория.
5. Нажмите **Deploy**. Переменные окружения не нужны.

## Изменение каталога

Редактируйте `lib/movies.ts`. Для каждого фильма укажите уникальный числовой `id` и все поля из типа `Movie`. Ссылки на страницы фильмов генерируются автоматически.

## Хранение

Избранное и список просмотра сохраняются в `localStorage` конкретного браузера. Они не синхронизируются между устройствами, не передаются на сервер и могут исчезнуть при очистке данных сайта.
